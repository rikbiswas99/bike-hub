# BIKE-HUB

AI-Powered Bike Recommendation and Used Bike Marketplace.

## Folders
| Folder      | What it is for                                  |
|-------------|-------------------------------------------------|
| `frontend/` | React + Vite + Tailwind website (what users see)|
| `backend/`  | FastAPI server (the brain, talks to database)   |
| `database/` | Database notes and setup SQL                    |
| `docs/`     | Guides and project documentation                |

Start with `docs/SETUP.md`.
